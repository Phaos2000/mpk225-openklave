# MPK225 / OpenKlave — Jazz Chord MIDI v0.2

**Experimental code only. Not installable MPK225 firmware. Do not flash.**

Independent firmware research for the Akai MPK225 (owner-reported factory OS v1.02) based on the [OpenKlave](https://github.com/sillsm/openklave) project.

The current host-tested C++17 prototypes implement a 24-type jazz chord engine and an event-to-MIDI pipeline. **MPK225 hardware mapping, USB behavior, full firmware build, and a tested factory-firmware recovery method are still outstanding.**

The source and tests are kept on a development branch until a full device-specific build and recovery plan have been verified. Never use upstream destructive flashing scripts on this device.

This project is not affiliated with Akai Professional or the OpenKlave author.
